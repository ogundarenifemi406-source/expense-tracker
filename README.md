# Expense Tracker

A responsive expense tracking web application built with HTML5, CSS3, and JavaScript.

## Features

- Add expenses
- Categorize expenses
- Calculate total spending
- Track spending by category
- Delete expenses
- Nigerian Naira (₦) currency formatting
- Enter key support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## What I Practiced

- DOM manipulation
- Event listeners
- JavaScript functions
- Objects
- Conditional logic
- Dynamic HTML elements
- Number calculations
